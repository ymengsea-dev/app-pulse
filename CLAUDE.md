# AppPulse

A lightweight native macOS app that shows which apps are using CPU, GPU, memory, and network, and which external hosts they talk to. It uses app icons, plain percentages, and friendly wording. Window-only (no menu bar item).

## Tech stack

Swift 6 with strict concurrency, SwiftUI, AppKit (icons, quitting apps), macOS 15+, no third-party dependencies. The Xcode project is generated by `xcodegen` from `project.yml` and is not committed. App Sandbox is off because `nettop` and IORegistry access need it, so the app cannot ship on the Mac App Store.

## Commands

```sh
swift test --package-path Packages/AppPulseKit   # all unit tests
xcodegen generate                                # regenerate AppPulse.xcodeproj
xcodebuild -project AppPulse.xcodeproj -scheme AppPulse -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/AppPulse.app

# Installer DMG (needs Finder running; no volume named AppPulse mounted)
xcodebuild -project AppPulse.xcodeproj -scheme AppPulse -configuration Release -derivedDataPath build build
scripts/dmg/make-dmg.sh build/Build/Products/Release/AppPulse.app build/AppPulse-<version>.dmg
```

The DMG window background is drawn by `scripts/dmg/make_background.py` with the `hand-drawn-matte-vector` skill's `handdrawn.py`. Export `background.png` (660 px wide) and `background@2x.png` (1320 px) with the skill's `export.py`. Icon positions in `make-dmg.sh` must match the background. Builds are ad-hoc signed and not notarized, so Gatekeeper blocks them on other Macs until the user clicks Open Anyway in Privacy & Security.

## Architecture

Clean Architecture with MVVM in the UI. Each layer is a target in `Packages/AppPulseKit`. SwiftPM can still see modules a target does not declare, so `Tests/DomainTests/ArchitectureTests.swift` enforces the import rules below.

```
Presentation ──> Application ──> Domain <── Platform
App (composition root) wires Platform implementations into Application
```

- `Domain`: entities, ports (protocols), pure rules. Foundation only.
- `Application`: `MonitoringEngine` (sampling loop), `DestinationHistory`, `QuitAppUseCase`. Imports `Domain` only.
- `Platform`: OS adapters. Imports `Domain` and system frameworks only.
- `Presentation`: SwiftUI views and view models. Never imports `Platform`.
- `App/CompositionRoot.swift`: the only place concrete types are chosen.

Rules:
- New OS data source: add a port in `Domain/Ports` and an adapter in `Platform`. Do not call OS APIs from other layers.
- A port returns data or throws. The engine turns a throw into `MetricStatus.unavailable` for that metric only. Never crash on bad OS data.
- Counter deltas go through `RateCalculator`. Do not write new delta logic.
- No database, DI framework, or third-party dependency without a clear need.

## Data sources

| Metric | Source | Stable public API? |
|---|---|---|
| CPU, memory | `proc_pid_rusage` (time is in Mach units, convert with `mach_timebase_info`) | Yes, but other users' processes are not readable |
| Per-app GPU | IORegistry `AGXDeviceUserClient`: `AppUsage.accumulatedGPUTime`, `IOUserClientCreator` | No |
| GPU total | IORegistry `PerformanceStatistics` "Device Utilization %" | No |
| Network | `nettop -L 1 -n -x -J bytes_in,bytes_out` text output | No |
| App grouping | Outermost `.app` in `proc_pidpath`, else `responsibility_get_pid_responsible_for_pid` | Responsible pid: no |
| Code signer | `SecStaticCodeCheckValidity` (resources skipped) and `SecCodeCopySigningInformation`, cached per path | Yes |
| Background vs. foreground | `NSRunningApplication.activationPolicy == .regular` means it has a window or Dock icon | Yes |

The Background page lists every process, including root's, which can be listed but not read. It shows signs, never proof: do not word it as "safe" or "malware".

A macOS update can break the non-public sources. After an OS update, recheck them with live values. Work that cannot be attributed to a readable process goes into the "macOS & other" row, so totals stay honest.

## Privacy

Destination history stays in memory for the session. Nothing is saved or sent anywhere, except normal reverse-DNS lookups to the Mac's configured DNS server. Test fixtures must not contain real addresses from a developer's machine.

## UI

Follow the `warm-editorial-ui` skill. Use only `Theme` tokens. Each page leads with one plain answer. Use the `hand-drawn-matte-vector` skill for the app icon and artwork. The icon's editable master is `Design/AppIcon.svg`.

An app's page follows the sidebar metric it was opened from (`AppRoute`). Memory, CPU, and GPU show that metric's process breakdown. Only Network shows connections.

Quit actions must always confirm and must never use `.keyboardShortcut(.defaultAction)`. Force Quit is offered only after a normal quit fails, and it warns about unsaved work.

Check real UI changes in light and dark mode, at minimum window size, and with long app names and empty states.
